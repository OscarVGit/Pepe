# Skill: financial-analysis

- **Purpose:** Ratio, trend, and bridge analysis on historicals.
- **When to use:** Quality-of-earnings reads, KPI packs.
- **Required inputs:** Historical financials + mapping.
- **Available tools:** Python/pandas, SQL.
- **Expected outputs:** Bridges, margins, growth/CAGR tables with sources.
- **Validation:** Recomputed in code; units/currency explicit.
- **Approval requirements:** Draft low.
- **Failure modes:** Inconsistent periods/currencies → normalise explicitly or stop.
