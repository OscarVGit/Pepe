# Skill: portfolio-monitoring

- **Purpose:** Recurring KPI/covenant/variance monitoring for portcos.
- **When to use:** Monthly/quarterly reporting, board prep.
- **Required inputs:** Actuals feed, KPI definitions, covenant terms.
- **Available tools:** Variance skill, debt skill, scheduler (Phase 5+).
- **Expected outputs:** Monitoring pack + breach alerts.
- **Validation:** Thresholds computed in code; alerts reproducible.
- **Approval requirements:** Internal packs medium; board distribution high.
- **Failure modes:** Late/missing actuals → carry-forward explicitly labelled.
