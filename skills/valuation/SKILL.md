# Skill: valuation

- **Purpose:** Triangulate value across multiples, DCF, and LBO-implied pricing.
- **When to use:** Entry pricing, exit reads, IC valuation sections.
- **Required inputs:** Comps/inputs per method, assumption log entries.
- **Available tools:** Deterministic multiples/DCF/LBO helpers.
- **Expected outputs:** Football-field summary with method weights and caveats.
- **Validation:** Each method recomputed; discrepancies explained, not averaged away.
- **Approval requirements:** Draft low; conclusions high.
- **Failure modes:** Single-method reliance → escalate for cross-check.
