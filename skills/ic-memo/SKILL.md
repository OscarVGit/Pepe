# Skill: ic-memo

- **Purpose:** Generate investment-committee memos from deal memory + artifacts.
- **When to use:** IC preparation and updates.
- **Required inputs:** Deal facts, cases, risks, terms checklist.
- **Available tools:** PowerPoint/Excel skills, deal memory.
- **Expected outputs:** Memo draft mapped to house structure + open-items list.
- **Validation:** Every number traces to source/assumption; no invented conclusions.
- **Approval requirements:** Draft medium; distribution high.
- **Failure modes:** Missing diligence → mark TBD and block conclusions.
