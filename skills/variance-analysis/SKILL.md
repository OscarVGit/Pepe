# Skill: variance-analysis

- **Purpose:** Actual vs budget/plan variance with driver attribution.
- **When to use:** Portfolio monitoring, management reporting.
- **Required inputs:** Actuals + plan by period/account.
- **Available tools:** Python/SQL variance engine.
- **Expected outputs:** Waterfall + commentary-ready drivers.
- **Validation:** Variances sum to total; FX/volume/price split where applicable.
- **Approval requirements:** Draft low.
- **Failure modes:** Mapping gaps → list unmapped lines, don't bury in "other".
