# Skill: three-statement

- **Purpose:** Build and reconcile IS/BS/CF with balance-sheet integrity.
- **When to use:** Historical reconciliation, forecast builds.
- **Required inputs:** Trial balance / accounts, mapping assumptions.
- **Available tools:** Python/SQL reconciliation, Excel skill.
- **Expected outputs:** Balanced statements + reconciliation log.
- **Validation:** BS balances every period; CF ties to BS movement.
- **Approval requirements:** Draft low; working-model changes medium.
- **Failure modes:** Unbalanced BS → blocked, list breaks, ask for bridge.
